제공해주신 **오류 보고서(ERROR_REPORT.md)**는 매우 체계적이며, 발생 가능한 거의 모든 예외 상황을 다루고 있습니다. 이 보고서를 바탕으로 **견고한(Robust) 애플리케이션**을 만들기 위한 **수정된 코드**를 제안해 드립니다.

보고서에서 지적한 **인증 실패, Rate Limit, 데이터 파싱 오류, 예외 처리** 등을 모두 반영하여 코드를 업그레이드했습니다.

### 1. `utils_github.py` (GitHub 연동 및 안정성 강화)

**개선점:**
*   **캐싱 도입 (`@st.cache_data`):** 보고서 3.1(Rate Limit) 해결을 위해 읽기 작업에 캐싱을 적용.
*   **예외 처리 세분화:** 인증 실패(401), 리포지토리 없음(404) 등을 구체적으로 처리.

```python
import streamlit as st
from github import Github, GithubException
import json
import time

# 캐시 사용 (TTL 60초) - API 호출 횟수 절약 (보고서 3.1 해결)
@st.cache_data(ttl=60)
def load_json(filename):
    """GitHub에서 JSON 파일을 읽어옵니다. 실패 시 빈 딕셔너리 반환."""
    try:
        # Secrets 검증
        if "GITHUB_TOKEN" not in st.secrets or "REPO_NAME" not in st.secrets:
            st.error("GitHub 설정(Secrets)이 누락되었습니다.")
            return {}

        g = Github(st.secrets["GITHUB_TOKEN"])
        repo = g.get_repo(st.secrets["REPO_NAME"])
        
        contents = repo.get_contents(filename)
        return json.loads(contents.decoded_content.decode())
        
    except GithubException as e:
        if e.status == 404:
            # 파일이 없는 경우 (첫 실행) -> 정상적인 빈 값 반환
            return {}
        elif e.status == 401:
            st.error("GitHub 인증 실패: Token을 확인하세요. (보고서 2.1)")
        elif e.status == 403:
            st.warning("API 요청 한도 초과 (Rate Limit). 잠시 후 다시 시도하세요. (보고서 3.1)")
        else:
            st.error(f"GitHub 오류 발생 ({e.status}): {e.data}")
        return {}
    except Exception as e:
        st.error(f"알 수 없는 오류: {str(e)}")
        return {}

def save_json(filename, data, message="Update data"):
    """GitHub에 JSON 데이터를 저장합니다."""
    try:
        g = Github(st.secrets["GITHUB_TOKEN"])
        repo = g.get_repo(st.secrets["REPO_NAME"])
        
        json_str = json.dumps(data, indent=4, ensure_ascii=False)
        
        try:
            # 파일이 있으면 Update
            contents = repo.get_contents(filename)
            repo.update_file(contents.path, message, json_str, contents.sha)
            st.success(f"{filename} 저장 성공!")
            # 저장 후 캐시 비우기 (최신 데이터 반영)
            load_json.clear()
        except GithubException as e:
            if e.status == 404:
                # 파일이 없으면 Create
                repo.create_file(filename, message, json_str)
                st.success(f"{filename} 생성 성공!")
                load_json.clear()
            else:
                raise e
                
    except Exception as e:
        st.error(f"저장 실패: {str(e)} (보고서 3.3)")
```

### 2. `utils_logic.py` (로직, 재시도 및 검증 강화)

**개선점:**
*   **재시도 로직:** Gemini API 호출 실패 시 3회 재시도 (보고서 5.1 해결).
*   **RSS 검증:** 피드 데이터가 비어있거나 날짜가 없는 경우 방어 코드 추가 (보고서 4.2 해결).
*   **날짜 기본값:** 날짜 파싱 실패 시 `오늘 날짜` 사용.

```python
import feedparser
import google.generativeai as genai
from datetime import datetime
import time
import streamlit as st
import logging

# 로깅 설정 (보고서 8.2 해결)
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

def fetch_rss_feeds(feed_urls):
    """RSS 피드를 수집하고 통합합니다."""
    all_entries = []
    
    for url in feed_urls:
        try:
            feed = feedparser.parse(url)
            # RSS 파싱 오류 체크 (보고서 4.2)
            if feed.bozo:
                logger.warning(f"RSS 파싱 경고 ({url}): {feed.bozo_exception}")
            
            if not feed.entries:
                logger.info(f"뉴스 없음: {url}")
                continue
                
            for entry in feed.entries:
                # 날짜 처리: 없으면 오늘 날짜
                pub_date = entry.get('published', datetime.now().strftime("%a, %d %b %Y %H:%M:%S +0000"))
                
                # 필요한 데이터만 추출
                all_entries.append({
                    'title': entry.get('title', 'No Title'),
                    'link': entry.get('link', ''),
                    'published': pub_date,
                    'summary': entry.get('summary', '')[:200]  # 내용 너무 길면 자름
                })
        except Exception as e:
            logger.error(f"RSS 수집 실패 ({url}): {e}")
            st.warning(f"{url} 수집 중 오류가 발생했습니다.")

    return all_entries

def analyze_with_gemini(news_list):
    """Gemini로 뉴스를 분석합니다. (재시도 로직 포함)"""
    if not news_list:
        return "수집된 뉴스가 없습니다."

    # Gemini 설정
    if "GEMINI_API_KEY" not in st.secrets:
        return "Gemini API Key가 설정되지 않았습니다."
        
    genai.configure(api_key=st.secrets["GEMINI_API_KEY"])
    model = genai.GenerativeModel('gemini-pro')
    
    # 프롬프트 구성
    prompt = f"""
    다음은 오늘 수집된 IT 뉴스 리스트야. 
    이 뉴스들을 분석해서 '오늘의 IT 뉴스룸' 브리핑을 작성해줘.
    
    형식:
    ## 📢 오늘의 핵심 요약 (3줄)
    1. ...
    2. ...
    3. ...

    ## 🔑 주요 키워드
    - #키워드1, #키워드2, ...

    ## 📰 주요 뉴스 단신 (Top 5)
    - **[제목](링크)**: 한 줄 평이나 요약
    
    뉴스 데이터:
    {str(news_list)}
    """

    # 재시도 로직 (보고서 5.1)
    max_retries = 3
    for attempt in range(max_retries):
        try:
            response = model.generate_content(prompt)
            return response.text
        except Exception as e:
            time.sleep(2)  # 2초 대기
            if attempt == max_retries - 1:
                return f"AI 분석 실패 (3회 시도): {str(e)}"
    return "분석 실패"
```

### 3. `app.py` (메인 UI 및 에러 핸들링)

**개선점:**
*   **Secrets 체크:** 앱 시작 시 필수 키값 확인 (보고서 2.1, 2.3 예방).
*   **Traceback 표시:** 에러 발생 시 개발자가 원인을 알 수 있도록 `expander`에 상세 로그 숨김 (보고서 8.3).
*   **사용자 피드백:** 로딩바(Spinner)와 성공/실패 메시지 명확화.

```python
import streamlit as st
import pandas as pd
import plotly.express as px
from datetime import datetime
import traceback # 상세 에러 확인용

# 모듈 임포트
import utils_github as git
import utils_logic as logic

# 1. 페이지 설정
st.set_page_config(page_title="나만의 뉴스룸", page_icon="📰", layout="wide")

# 2. 필수 설정 확인 (보고서 7.2 - 단계별 디버깅 시작)
if not all(k in st.secrets for k in ["GITHUB_TOKEN", "REPO_NAME", "GEMINI_API_KEY"]):
    st.error("🚨 필수 설정(Secrets)이 누락되었습니다. .streamlit/secrets.toml을 확인하세요.")
    st.stop()

# 3. 사이드바 메뉴
menu = st.sidebar.selectbox("메뉴 선택", ["📰 뉴스룸 (메인)", "⚙️ 관리 대시보드"])

# ==========================================
# 메인 화면: 뉴스룸
# ==========================================
if menu == "📰 뉴스룸 (메인)":
    st.title("📰 1인 IT 뉴스룸")
    st.caption("AI가 매일 아침 정리해주는 나만의 IT 브리핑")

    # 데이터 로드
    news_data = git.load_json("news_data.json")
    
    # 날짜 선택
    today = datetime.now().strftime("%Y-%m-%d")
    dates = sorted(news_data.keys(), reverse=True) if news_data else [today]
    
    if not news_data:
        st.info("📭 아직 저장된 뉴스가 없습니다. '관리 대시보드'에서 뉴스를 수집해주세요.")
    else:
        selected_date = st.selectbox("날짜 선택", dates)
        
        if selected_date in news_data:
            content = news_data[selected_date]
            
            # 2단 레이아웃
            col1, col2 = st.columns([2, 1])
            
            with col1:
                st.markdown(content.get('analysis', '분석 내용 없음'))
                
            with col2:
                st.subheader("🔗 원본 링크")
                for item in content.get('raw_news', [])[:10]:
                    st.markdown(f"- [{item['title']}]({item['link']})")

            # 통계 업데이트 (접속자 수)
            # 세션 스테이트를 사용하여 새로고침 시 중복 카운트 방지
            if "visited" not in st.session_state:
                stats = git.load_json("stats.json")
                stats["total_visits"] = stats.get("total_visits", 0) + 1
                
                # 날짜별 방문자 (보고서 3.3 충돌 방지 위해 try-except 안에서 조용히 처리)
                try:
                    git.save_json("stats.json", stats, "Update visitor stats")
                    st.session_state["visited"] = True
                except:
                    pass # 통계 저장은 실패해도 메인 기능에 영향 없도록

# ==========================================
# 관리 대시보드
# ==========================================
elif menu == "⚙️ 관리 대시보드":
    st.title("⚙️ 관리 대시보드")
    
    # 탭 구분
    tab1, tab2, tab3 = st.tabs(["RSS 관리", "수집 및 분석", "시스템 상태"])
    
    # 1. RSS 관리
    with tab1:
        st.subheader("RSS 피드 목록")
        feeds_data = git.load_json("feeds.json")
        current_feeds = feeds_data.get("urls", [])
        
        new_feed = st.text_input("새 RSS URL 추가")
        if st.button("추가"):
            if new_feed and new_feed not in current_feeds:
                current_feeds.append(new_feed)
                git.save_json("feeds.json", {"urls": current_feeds}, "Add RSS feed")
                st.rerun()
        
        st.write("---")
        st.write("등록된 피드:")
        for url in current_feeds:
            c1, c2 = st.columns([4, 1])
            c1.text(url)
            if c2.button("삭제", key=url):
                current_feeds.remove(url)
                git.save_json("feeds.json", {"urls": current_feeds}, "Remove RSS feed")
                st.rerun()

    # 2. 수집 및 분석 (핵심 기능)
    with tab2:
        st.subheader("뉴스 수집 및 AI 분석 실행")
        if st.button("🚀 실행 (Start)"):
            status_area = st.empty()
            try:
                # 1. RSS 불러오기
                feeds_data = git.load_json("feeds.json")
                urls = feeds_data.get("urls", [])
                
                if not urls:
                    st.error("등록된 RSS 피드가 없습니다.")
                else:
                    with st.spinner("1/3 RSS 뉴스 수집 중..."):
                        raw_news = logic.fetch_rss_feeds(urls)
                    
                    # 2. AI 분석
                    with st.spinner("2/3 Gemini AI 분석 중..."):
                        analysis_result = logic.analyze_with_gemini(raw_news)
                    
                    # 3. GitHub 저장
                    with st.spinner("3/3 결과 저장 중..."):
                        today_str = datetime.now().strftime("%Y-%m-%d")
                        
                        # 기존 데이터 로드
                        full_data = git.load_json("news_data.json")
                        
                        # 오늘 데이터 업데이트
                        full_data[today_str] = {
                            "analysis": analysis_result,
                            "raw_news": raw_news,
                            "updated_at": datetime.now().strftime("%H:%M:%S")
                        }
                        
                        git.save_json("news_data.json", full_data, f"News update: {today_str}")
                    
                    st.success("✅ 모든 작업이 완료되었습니다!")
                    st.balloons()
                    
            except Exception as e:
                st.error("❌ 작업 중 오류가 발생했습니다.")
                # 상세 에러 로그 (보고서 8.3 해결)
                with st.expander("오류 상세 내용 (개발자용)"):
                    st.code(traceback.format_exc())

    # 3. 시스템 상태 (통계)
    with tab3:
        st.subheader("접속자 통계")
        stats = git.load_json("stats.json")
        st.metric("총 방문자 수", stats.get("total_visits", 0))
        
        # Secrets 상태 점검
        st.write("---")
        st.subheader("시스템 연결 상태")
        st.success("GitHub Token: OK") if "GITHUB_TOKEN" in st.secrets else st.error("GitHub Token: Missing")
        st.success("Gemini API: OK") if "GEMINI_API_KEY" in st.secrets else st.error("Gemini API: Missing")

```
